# Changelog

## 0.2.0 — 2026-11-08

- Multiple products can share one explicitly named sibling repository’s Docker services and existing data.
- Local service clients can discover the gateway port and trust its certificate authority without disabling TLS verification.

## 0.1.1 — 2026-11-06

- Public release downloads allow pinned npm installation without registry credentials.
- Publish the exact same archive to GitHub Packages and GitHub Releases.

## 0.1.0 — 2026-11-06

- Configuration-driven process startup, environment setup, readiness, checks and reset hooks.
- Per-machine ports, checkout isolation and private local HTTPS routing.
- Optional Docker Compose integration that retains existing projects and volumes.
- Published CLI, reusable helpers and versioned JSON configuration schema.
